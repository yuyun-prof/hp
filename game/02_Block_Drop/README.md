# Web Tetris v2

## 주요 변경
- 게임 보드 표시 크기를 270 x 540px로 축소해 세로 잘림 완화
- 점수, 다음 블록, 조작법을 오른쪽 패널에 가로 배치
- 줄 제거 시 플래시/분산 애니메이션 추가
- 줄 점수 배율: 1줄 x1, 2줄 x1.5, 3줄 x2, 4줄 x4
- 연속 제거 콤보: 첫 제거 x1, 2연속 x2, 3연속 x3, 4연속 이상 x4
- 줄을 지우지 못한 채 블록을 놓으면 콤보 초기화

## 홈페이지 연결
```html
data-game-src="game/02_tetris/index.html"
data-game-width="820"
data-game-height="620"
```
