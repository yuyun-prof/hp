# Spider Nine

브라우저에서 실행되는 스빠이더 카드게임입니다. (Spider Nine 게임과 비슷 혹은 같음)

## 실행
1. 압축을 풉니다.
2. `sp_index.html`을 더블클릭합니다.
3. 별도 서버나 설치가 필요 없습니다.

## 파일
- `sp_index.html` : 게임 화면
- `sp_style.css` : UI 및 애니메이션
- `sp_game.js` : 카드 규칙, 점수, 키보드/마우스 조작, 효과음

## 난이도
- 쉬움: 1무늬
- 중간: 2무늬
- 어려움: 4무늬
- 각 난이도의 1/2/3단계는 104/156/208장으로 증가합니다.

## 키보드
- 방향키: 열/카드 이동
- Space: 카드 집기 또는 놓기
- Backspace: 되돌리기
- H: 힌트
- D: 새 카드 배분
- N: 새 게임
- Esc: 선택 취소

## 참고
브라우저 보안 정책상 첫 사용자 입력 전에는 효과음이 재생되지 않을 수 있습니다.

## V3 완성 시퀀스 연출
- 같은 무늬 K부터 A까지 완성하면 13장이 금빛으로 점등됩니다.
- A부터 K까지 카드가 연속적으로 보관함으로 날아가며 한 장씩 사라집니다.
- 카드별 상승 음, 잔광 입자, 보관함 충돌 링 및 별 파티클이 재생됩니다.
- 연출 중에는 중복 입력이 잠시 잠겨 게임 상태가 꼬이지 않습니다.

## V4 변경 사항
- 더블클릭 자동 이동은 빈 열보다 숫자가 맞는 카드 위를 우선합니다.
- 숫자가 맞는 목적지가 여러 곳이면 그중 하나를 무작위로 선택합니다.
- 맞는 카드 위가 없을 때만 빈 열로 이동합니다.
- 카드 선택·이동·뒤집기·배분 소리를 외부 음원 없이 합성한 종이/트럼프 마찰음으로 개선했습니다.

## 명칭 및 공개 배포 참고
- 게임명은 고유한 `Spider Nine`을 유지합니다.
- Microsoft Solitaire Collection의 로고, 그래픽, 음원 또는 소스 코드는 사용하지 않습니다.
- 공개 배포 전 서비스 지역의 상표 검색과 최종 법률 검토가 필요한 경우 별도로 진행하세요.
